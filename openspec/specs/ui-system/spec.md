# Capability: Warm Alabaster Daylight & Vercel Obsidian Dark UI System

## Overview
Mindora adheres to a calm cross-generational visual system anchored on `Warm Alabaster` Daylight (fresh-install default) and optional `Vercel Obsidian-Zinc` Night mode via `MindTokens` (`ThemeExtension`), hairline borders, zero purple, zero pitch-black `#000000`, and crisp typography.

## Requirements

### Requirement: Light & Dark Mode Architecture
- **Daylight (`Warm Alabaster` — Default):** Ground `#FAF9F6`, card surface `#FFFFFF`, soft well `#F3F1EC`, hairline border `#E5E3DD`, carbon ink `#111114`, primary CTA `#111114` (`#FFFFFF` onPrimary), focus teal `#0D9488`.
- **Night (`Vercel Obsidian-Zinc` — Optional):** Ground `#09090B`, card surface `#111114`, soft well `#18181C`, hairline border `#27272A`, crisp ink `#FAFAFA`, primary CTA `#FAFAFA` (`#09090B` onPrimary). Never pitch-black `#000000` and zero purple.
- **Corner Radii & Touch Targets:** Rounded surfaces (`20dp–24dp` cards), minimum `56dp` primary buttons (`48dp` minimum everywhere else), body `16sp` (`18.5sp` Larger Text), hard floor `12.0sp`.

### Requirement: Six Vivid Mood Accents
The system SHALL pair icon + label alongside six desaturated mood accents:
1. **Good:** `#FFC93C`
2. **Calm:** `#2DD4BF`
3. **Worried:** `#38BDF8`
4. **Annoyed:** `#FF7A59`
5. **Low:** `#94A3B8`
6. **Restless:** `#FBBF24`

### Requirement: No Emoji Directive
Emojis are strictly prohibited across all buttons, chips, app bars, dialogs, and badges. All iconography MUST use vector icons (`Icons.*`) or clean custom painters.
